# macUtilities — правила для ассистентов (Claude Code и Codex)

Репозиторий самописных утилит для macOS. Делимся с друзьями, поэтому всё должно собираться у них из исходников одной командой.

## Состав
- `Chelka/` — панель в вырезе экрана (Swift, AppKit + SwiftUI, несколько файлов в `Sources/`).
- `DockToggle/` — скрытие активного приложения повторным кликом по Доку (Swift, один файл).

## Как устроена каждая утилита
- Своя папка в корне: `Sources/*.swift`, `Info.plist`, `build.sh`, `README.md` на русском.
- `./build.sh` собирает `build/<Имя>.app` через `swiftc` (без Xcode-проекта, без сторонних зависимостей), подписывает ad-hoc. `./build.sh install` кладёт в `~/Applications`.
- Процессор: `build.sh` сам выбирает `arm64` (Apple Silicon) или `x86_64` (Intel) по `sysctl hw.optional.arm64`; `ARCH=x86_64 ./build.sh` — проверить сборку под Intel. Минимальная macOS указана в `Info.plist` и `build.sh`.
- Bundle ID вида `local.<Имя>`. Менять его нельзя без нужды: macOS сбросит выданные разрешения.
- Комментарии в коде и тексты интерфейса — на русском.

## Новая утилита
1. Создать папку по образцу выше.
2. Добавить строку в таблицу корневого `README.md` и имя утилиты в `install.sh` (списки `all` и `min_macos`, подсказка про разрешения в конце).
3. Проверить: сборка без ошибок и предупреждений; если есть интерфейс — картинка через режим отрисовки (как `--snapshot` у Chelka), потому что у ассистента нет доступа к записи экрана.
4. Перед коммитом проверить на секреты и личные данные (skill `team-share-check`): никаких путей машины, серийников, почты, токенов.

## Установщик
- `install.sh` в корне ставит и обновляет утилиты одной командой (`curl … | zsh`). Команда берёт скрипт и исходники с GitHub, поэтому давать её людям можно только после push и проверки `curl` по raw-ссылке (код 200). Иначе у них молча ничего не поставится (так было 2026-11-11). Проверять без установки: `MACUTILS_REPO=file://<репо> MACUTILS_DIR=<временная папка> MACUTILS_BUILD_ONLY=1`, подавая скрипт через `| zsh`.

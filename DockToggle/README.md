# DockToggle

Маленькая программа для строки меню macOS: **повторный клик по иконке активного приложения в Доке прячет его** (как ⌘H). Следующий клик возвращает приложение обратно, как обычно делает macOS.

## Как работает
- Перехватывает левый клик мыши (`CGEventTap`) и через Accessibility API смотрит, по какой иконке Дока кликнули.
- Если это иконка **того приложения, что сейчас активно**, и у него есть окна на экране, клик не уходит в Док, а приложение прячется (`NSRunningApplication.hide()`).
- Во всех остальных случаях клик проходит в Док без изменений:
  - клик с ⌘, ⌥, ⌃ или ⇧;
  - у приложения нет окон на экране (всё свёрнуто, окно на другом рабочем столе, у Finder нет окон);
  - клик по папкам, Корзине, стопкам.
- Ничего не пишет на диск, кроме одной своей настройки (вкл/выкл), и в сеть не ходит.

## Сборка и установка
```bash
./build.sh            # собрать в build/DockToggle.app
./build.sh install    # собрать и положить в ~/Applications
```
Нужны Command Line Tools (`swiftc`). Подпись ad-hoc, без аккаунта разработчика.

## Первый запуск
1. Открыть `~/Applications/DockToggle.app`.
2. macOS попросит доступ: **Настройки → Конфиденциальность и безопасность → Универсальный доступ** → включить DockToggle.
3. Значок появится в строке меню. В его меню:
   - «Прятать повторным кликом» — включить/выключить;
   - «Запускать при входе» — автозапуск;
   - «Выйти из DockToggle».

## Ограничения
- Иконку **активного** приложения в Доке нельзя перетащить обычным кликом: зажми ⌘ (или сначала переключись на другое приложение).
- После каждой пересборки подпись меняется, и macOS сбрасывает доступ. Тогда в «Универсальном доступе» удали старую запись DockToggle кнопкой «−» и добавь заново.

## Удаление
Выйти из программы через меню, удалить `~/Applications/DockToggle.app`, убрать запись в «Универсальном доступе».
